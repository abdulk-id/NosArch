# System Style

## Usage

### Colors

Order (in terms of brightness):

1. Tertiary (darkest)
2. Secondary (darker)
3. Primary (dark)

Color uses:

- Primary Background:
    - Swaync (style.css):
        - Background of notification boxes in notification center (`center-notification-bg`)
        - Background of UI elements in notification center (including the header text, DND toggle, media player controls) (`background`)
- Secondary Background:
    - Swaync (style.css):
        - Popup notification background (`notification-bg`)
        - Background of lower layer of notification center (`center-bg`)
    - Waybar (style.css): `background`
- Tertiary Background:
    - Terminal Background
    - Swayosd (style.css):
- Primary Foreground:
    - Swaync (style.css): `text`
    - Waybar (style.css): `foreground`
- Secondary Foreground:
    - Swaync (style.css): `text-alt`
- Accent:
    - Swaync (style.css): `accent-color`
